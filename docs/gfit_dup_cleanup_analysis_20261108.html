核心结论

「重名」≠「重复」。142 个重名组里，只有 14 组连图片文件名都完全相同（真重复）； 剩下 128 组图片各不相同 —— 那是不同变体（不同器械/角度/握法），不是冗余条目。

按 2026-11-04 那次评估的结论：同名不同 id 是合法数据，强行归组反而会误标。删掉一个变体 = 删掉一个真实存在的动作。

判定方法

不是"组内有没有更好的版本"这种粗判，而是逐条模拟：把候选动作按 id 升序， 对每一条假设"如果删它"，检查全库是否还有同英文名 / 同中文名的存活者； 有就删，没有就保留并记下原因。校验结果：零孤立、零引用、零有视频。

保留的 174 条 —— 为什么不删

它们的英文名虽然是重复的，但组内每个成员挂着不同的中文名 （如 Finger Curls 组下有「手指弯举」「指屈伸」「手指卷曲」三个不同中文名）。 删掉任一条，那个中文名就在全库消失了 —— 而小程序是中文界面， 用户搜「指屈伸」会搜不到。
